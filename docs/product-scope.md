# Product Scope

## Purpose and current behavior

Provide fast, affordable, local screening for AI-generated songs. The application includes a web interface, HTTP API, command line, and a bundled CPU-only ONNX detector based on [lofcz/ai-music-detector](https://github.com/lofcz/ai-music-detector). No model download, external audio upload, GPU, or training dataset is required for inference.

The detector analyzes spectral fakeprint features in the first 300 seconds of a recording. It targets known Suno ≤ 5 and Udio ≤ 1.5 artifacts. It does not validate every AI generator, identify a generator, locate generated passages, or determine authorship or copyright ownership.

## Inputs

The HTTP service accepts one audio file up to 100 MiB. Audio must contain at least 10 seconds, use a native sample rate of 16–96 kHz, and be mono or stereo. The service accepts MP3, WAV, FLAC, M4A, AAC, OGG, Opus, AIFF/AIF, and WMA extensions, subject to installed decoder support. The CLI accepts local files without the HTTP upload-size limit; decoding and audio limits still apply.

Invalid, unsupported, silent, and insufficient-evidence inputs produce explicit errors rather than a human-created assessment. Input metadata and filenames are not classifier features.

## Assessments

| Assessment | Initial decision policy |
| --- | --- |
| `likely_ai_generated` | AI score > 0.6. |
| `likely_human_created` | AI score < 0.4. |
| `uncertain` | 0.4 ≤ AI score ≤ 0.6. |

The score is the model's sigmoid output, not a calibrated probability of correctness. The uncertainty band is an unvalidated product policy. The result includes a filename, score, assessment, original and analyzed duration, truncation flag, processing time, model version and provenance, and warnings. See [Operations](operations.md) for the exact contract.

## Reference labels for evaluation

| Label | Meaning |
| --- | --- |
| Fully AI-generated | The musical audio was generated by an AI system. |
| Human-created | The recording has documented human production provenance and no known generative audio contribution. |
| Mixed | The recording combines generated and human-created audio, such as generated vocals over human accompaniment. |
| Unknown | Provenance is insufficient to assign a reliable reference label. |

Begin binary evaluation with fully AI-generated and human-created recordings. Report mixed and unknown recordings separately until a validated policy supports them. Ordinary editing, mastering, pitch correction, and digital instruments alone do not establish generative audio use.

## Evidence and next validation

Upstream reports 99.88% on its own held-out set. This project's 99% accuracy objective remains unverified. Validate quality and the uncertainty band with an authorized, representative dataset, then measure end-to-end latency and cost on the intended hardware. Use the [Evaluation Plan](evaluation.md) to report false positives, false negatives, and decision coverage alongside accuracy.

## Data handling and deployment scope

Inference runs on the application host. Uploaded audio is held in temporary storage and removed when request handling finishes; there is no results database or training pipeline. The server has no authentication and defaults to localhost. Public or shared deployment requires a separate access, transport, resource, and retention design; see [Operations](operations.md).
